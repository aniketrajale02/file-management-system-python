# File Management System

This is a simple File Management System built using Python. The project allows users to manage files and folders through a menu-driven interface. It was created to practice Python fundamentals such as file handling, exception handling, functions, loops, and the Pathlib module.

## Features

* Create new folders
* View existing files and folders
* Rename folders
* Delete folders
* Create new files
* Read file contents
* Update file contents
* Delete files

## Technologies Used

* Python
* Pathlib
* File Handling
* Exception Handling

## How to Run
```bash
python file_manager.py
```
## Learning Outcomes

Through this project, I gained hands-on experience with:

* Working with files and directories using Pathlib
* Implementing CRUD operations
* Using functions to organize code
* Handling errors with try-except blocks
* Building menu-driven console applications
